РОЗДІЛ 01

Логіка прийняття рішень

Досі всі наші програми виконувалися як рецепт: рядок за рядком, завжди однаково. Але справжні програми щохвилини приймають рішення: банкомат перевіряє, чи вистачає грошей, сайт — пароль, навігатор — куди повернути.

Розгалуження — місце в алгоритмі, де програма обирає один із кількох шляхів. На блок-схемі це ромб із виходами «так» і «ні». У Python ромб стає інструкцією if.

Аналогія

Розгалуження — розвилка на дорозі з табличкою. Табличка — умова, а дорога залежить від того, що на ній написано. Пройти обома дорогами одночасно не можна.

РОЗДІЛ 02

Інструкція if

Найпростіше розгалуження: «якщо умова істинна — виконай дію, інакше нічого не роби». Торкніться частин коду, щоб побачити, що означає кожна.

if cups >= 3:
    print("Знижка 10%")
print("Замовлення прийнято")
Торкніться будь-якого елемента коду вище, щоб побачити пояснення.

Спробуйте передбачити вивід для cups = 4:

01_if.py
# if: виконати блок, лише якщо умова істинна
cups = 4

if cups >= 3:
    print("Діє знижка 10%")
    print("Дякуємо за велике замовлення!")

print("Замовлення прийнято")
Діє знижка 10% Дякуємо за велике замовлення! Замовлення прийнято # якщо cups = 2 — виведеться лише останній рядок

РОЗДІЛ 03

Дві гілки: if-else

Коли потрібна дія і для «так», і для «ні», додають else — «інакше». Виконається рівно одна з двох гілок.

02_if_else.py
# if-else: рівно одна з двох гілок
hour = 21

if 8 <= hour < 20:
    print("Кав'ярня відчинена")
else:
    print("Кав'ярня зачинена, приходьте о 8:00")
Кав'ярня зачинена, приходьте о 8:00 # 8 <= 21 < 20 — хибно, бо 21 не менше 20
Типова помилка

else не має власної умови: else hour > 20: — синтаксична помилка. І він має йти одразу після тіла if, на тому самому рівні відступу.

РОЗДІЛ 04

Багато гілок: if-elif-else

Знижка залежить від суми: від 1000 грн — 15 %, від 500 — 10 %, від 200 — 5 %, інакше — 0. Для кількох варіантів є elif — «інакше, якщо».

03_elif.py
# if-elif-else: кілька гілок, спрацьовує перша істинна
total = 640

if total >= 1000:
    discount = 15
elif total >= 500:
    discount = 10
elif total >= 200:
    discount = 5
else:
    discount = 0

print(f"Сума: {total} грн, знижка: {discount}%")
Сума: 640 грн, знижка: 10%

Запам'ятати

У каскаді elif виконується не більше однієї гілки. Навіть якщо істинні кілька умов, спрацює лише перша.

РОЗДІЛ 05

Порядок умов має значення

Найпідступніша помилка теми. Програма ставить оцінку за 12-бальною шкалою. Обидві вкладки відрізняються лише порядком гілок. Студент має 11 балів — що він отримає?

04_order_bad.py
# Помилка порядку: широка умова стоїть першою
score = 11

if score >= 4:
    print("Задовільно")
elif score >= 7:
    print("Добре")
elif score >= 10:
    print("Відмінно")
Задовільно # 11 >= 4 — істинно, Python зупинився. Гілки >= 7 і >= 10 недосяжні # і жодного повідомлення про помилку!
05_order_good.py
# Правильно: від найвужчої умови до найширшої
score = 11

if score >= 10:
    print("Відмінно")
elif score >= 7:
    print("Добре")
elif score >= 4:
    print("Задовільно")
else:
    print("Незадовільно")
Відмінно

Як перевірити каскад: по одному значенню з кожного діапазону і всі значення точно на межах.

ЗначенняОчікуваноЧому саме воно
12Відмінноверх шкали
10Відмінномежа: >=, а не >
9Добресередина діапазону
7, 4Добре, Задовільномежі
3Незадовільногілка else
Типова помилка

Неправильний порядок не дає жодних повідомлень і проходить перевірку на «зручних» даних. Тестуйте значеннями з кожної гілки та межовими.

РОЗДІЛ 06

Вкладені умови

Немає сенсу питати «чи є ще кава?», якщо кав'ярня зачинена. Тоді одне розгалуження ставлять всередину іншого. Кожен рівень — ще 4 пробіли.

06_nested.py
# Вкладені умови: друге питання має сенс лише після першого
is_open = True
cups_left = 0

if is_open:
    if cups_left > 0:
        print("Можна замовляти")
    else:
        print("Відчинено, але кава закінчилась")
else:
    print("Зачинено")
Відчинено, але кава закінчилась
Запам'ятати

Який else до якого if належить, визначає відступ. Зсунете else на 4 пробіли — зміниться логіка програми.

РОЗДІЛ 07

Вкладені чи складені умови

Ту саму логіку можна записати без вкладення — через and та elif. Порівняйте вкладки: результат однаковий.

06_nested.py
# Вкладені умови: друге питання має сенс лише після першого
is_open = True
cups_left = 0

if is_open:
    if cups_left > 0:
        print("Можна замовляти")
    else:
        print("Відчинено, але кава закінчилась")
else:
    print("Зачинено")
07_combined.py
# Те саме, але через and — без вкладення
is_open = True
cups_left = 0

if is_open and cups_left > 0:
    print("Можна замовляти")
elif is_open:
    print("Відчинено, але кава закінчилась")
else:
    print("Зачинено")
Відчинено, але кава закінчилась # той самий результат, на рівень відступу менше

Вкладені

Видно ієрархію питань; кожну умову перевіряють один раз. Але код «їде» вправо.

Аналогіяохоронець питає «є квиток?», а потім «яке місце?»

Складені

Плоский код, читається як речення. Але деякі умови повторюються.

Аналогіятабличка «вхід лише з квитком і паспортом»

Практичне правило

Один рівень вкладення — нормально, два — терпимо, три й більше — час переписувати через and, or та elif.

РОЗДІЛ 08

Тернарний оператор

Коли треба лише обрати одне з двох значень, чотири рядки if-else — надто громіздко:

Схема
значення_так if умова else значення_ні
08_ternary.py
# Тернарний оператор: if-else в один рядок
cups = 4

size = "велике" if cups >= 3 else "звичайне"
print("Замовлення:", size)

price = 55
final = price * 0.9 if cups >= 3 else price
print("Ціна чашки:", final)

print("Парне" if cups % 2 == 0 else "Непарне")
Замовлення: велике Ціна чашки: 49.5 Парне
Тернарний доречнийКраще звичайний if-else
обираємо одне з двох значеньу гілках треба виконати дії
обидва варіанти короткіне вміщується в один рядок
одна умовапотрібен ще й elif
Не вкладайте

Запис a if x else b if y else c технічно працює, але читається погано. Для трьох і більше варіантів пишіть if-elif-else.

РОЗДІЛ 09

Булеві значення в умовах: truthy і falsy

В умові може стояти будь-яке значення — Python сам перетворить його на True чи False. Оберіть значення й перевірте свою інтуїцію:

09_truthy.py
# Будь-яке значення в умові стає True або False
print("0       ->", bool(0))
print("7       ->", bool(7))
print("-1      ->", bool(-1))
print("0.0     ->", bool(0.0))
print("''      ->", bool(""))
print("'0'     ->", bool("0"))
print("' '     ->", bool(" "))
print("'Латте' ->", bool("Латте"))
print("None    ->", bool(None))
0 -> False 7 -> True -1 -> True 0.0 -> False '' -> False '0' -> True ' ' -> True 'Латте' -> True None -> False
Довгий записКороткий (PEP 8)
if name != "":if name:
if name == "":if not name:
if cups != 0:if cups:
if is_open == True:if is_open:
if is_open == False:if not is_open:
11_bool_style.py
# Як порівнювати з True: три записи, один правильний
is_open = True

if is_open == True:      # працює, але так не пишуть
    print("1) відчинено")
if is_open is True:      # теж зайве
    print("2) відчинено")
if is_open:              # так правильно (PEP 8)
    print("3) відчинено")
1) відчинено 2) відчинено 3) відчинено # усі три працюють, але PEP 8 рекомендує третій: «якщо відчинено»
РОЗДІЛ 10

Розгалуження разом із try-except

Введення перевіряють двічі: try-except — чи це взагалі число, а if — чи число має сенс. Пройдіть усі п'ять кроків:

12_input_branch.py
# Розгалуження + захист введення з теми 2
try:
    age = int(input("Ваш вік: "))
except ValueError:
    print("Вік має бути цілим числом")
else:
    if age < 0 or age > 120:
        print("Такого віку не буває")
    elif age < 18:
        print("Енергетики продаємо лише з 18 років")
    else:
        print("Можна замовити будь-який напій")

Оберіть, що введе користувач:

Ваш вік: 15 Енергетики продаємо лише з 18 років
Ваш вік: abc Вік має бути цілим числом # спрацював except ValueError
Ваш вік: 150 Такого віку не буває # число є, але безглузде — перша гілка if
Ваш вік: 25 Можна замовити будь-який напій

Підсумкова програма теми

13_cafe_final.py
"""Кав'ярня «Байт»: підсумкова програма теми 3.
Знижка за сумою, бонус для студентів, перевірка оплати.
"""
PRICE = 55.0

try:
    cups = int(input("Скільки чашок? "))
    is_student = input("Студент? (так/ні): ") == "так"
    paid = float(input("Скільки дали грошей? "))
except ValueError:
    print("Помилка: потрібні числа")
else:
    if cups <= 0:
        print("Кількість чашок має бути додатною")
    else:
        total = cups * PRICE
        # 1) знижка за сумою: від найвужчої умови
        if total >= 500:
            discount = 15
        elif total >= 200:
            discount = 10
        else:
            discount = 0
        # 2) окремий if: бонус додається до будь-якої знижки
        if is_student:
            discount += 5

        final = total * (100 - discount) / 100
        print(f"Сума: {total:.2f}, знижка {discount}%")
        print(f"До сплати: {final:.2f} грн")

        # 3) вистачає грошей чи ні
        if paid >= final:
            print(f"Здача: {paid - final:.2f} грн")
        else:
            print(f"Не вистачає {final - paid:.2f} грн")
Скільки чашок? 4 Студент? (так/ні): так Скільки дали грошей? 250 Сума: 220.00, знижка 15% До сплати: 187.00 грн Здача: 63.00 грн # знижка 10% за суму + 5% студенту: бонус — окремий if, не elif

один каскад if-elif-elseкілька окремих if
«знижка 15, 10 або 0 %»«знижка за суму і бонус студенту»
