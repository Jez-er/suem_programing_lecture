РОЗДІЛ 01

Вираз: операнди, оператори, результат

Минулого разу ми клали у змінні готові значення. Але програми пишуть заради обчислень — щоб із одних даних отримати інші.

Вираз — це запис, який Python обчислює й перетворює на одне значення. Він складається з операндів (значень і змінних) та операторів (знаків дії).

Запам'ятати

Знак = у програмуванні — це не «дорівнює», а «поклади результат у». Саме тому запис x = x + 1, безглуздий у математиці, для Python цілком нормальний. Для порівняння є окремий оператор ==.

РОЗДІЛ 02

Арифметичні оператори

Їх сім. П'ять ви знаєте зі школи, а два — // і % — потребують окремої уваги.

Перш ніж натискати «Запустити», спробуйте передбачити всі сім результатів.

01_operators.py
# Сім арифметичних операторів на одній парі чисел
a = 17
b = 5

print("a + b  =", a + b)    # додавання
print("a - b  =", a - b)    # віднімання
print("a * b  =", a * b)    # множення
print("a / b  =", a / b)    # ділення (завжди float)
print("a // b =", a // b)   # ціла частина
print("a % b  =", a % b)    # остача
print("a ** b =", a ** b)   # степінь
a + b = 22 a - b = 12 a * b = 85 a / b = 3.4 a // b = 3 a % b = 2 a ** b = 1419857 # / завжди дає float: навіть 10 / 5 поверне 2.0

Типова помилка

Знак множення не можна пропускати, як у математиці: 2x або 2(a + b) — синтаксична помилка. Пишіть 2 * x і 2 * (a + b).

РОЗДІЛ 03

Ділення націло та остача: де вони потрібні

Для 17 і 5: 17 = 5 · 3 + 2. Отже 17 // 5 — це 3 (скільки разів вмістилося), а 17 % 5 — це 2 (що лишилося). Оберіть задачу й подивіться, який оператор її розв'язує.

hours = seconds // 3600      # скільки повних годин
rest = seconds % 3600        # що лишилося
minutes = rest // 60
sec = rest % 60

print(hours, "год", minutes, "хв", sec, "с")
print("Парне число 17?", 17 % 2 == 0)
print("Остання цифра 2025:", 2025 % 10)
print("divmod(17, 5) =", divmod(17, 5))

РОЗДІЛ 04

Пріоритет операцій і дужки

Вираз 2 + 3 * 4 дає 14, а не 20: множення виконується раніше за додавання. Порядок виконання називають пріоритетом.

Два рядки нижче — найпідступніші в усій темі. Спробуйте вгадати результат 2 ** 3 ** 2 і -2 ** 2.

03_priority.py
# Пріоритет операцій: дужки змінюють результат
print(2 + 3 * 4)        # спершу множення
print((2 + 3) * 4)      # дужки — найвищий пріоритет
print(2 ** 3 ** 2)      # степінь рахується справа наліво
print((2 ** 3) ** 2)
print(-2 ** 2)          # спершу степінь, потім мінус
print((-2) ** 2)
print(10 - 4 - 3)       # однаковий рівень — зліва направо
print(100 / 10 / 2)
14 20 512 64 -4 4 3 5.0 # 2 ** 3 ** 2 = 2 ** 9 = 512: степінь рахується справа наліво # -2 ** 2 = -(2 ** 2) = -4: степінь старший за унарний мінус
РівеньОперації
1( ) — дужки
2** — степінь (справа наліво)
3-x — унарний мінус
4* / // %
5+ -
6< > == !=
7not → and → or
Правило професіонала

Вчити таблицю напам'ять не треба. Треба запам'ятати: є сумнів — ставте дужки. Вони нічого не сповільнюють, зате роблять намір очевидним. Дріб «a плюс b поділити на 2» мовою Python — це (a + b) / 2, а не a + b / 2.

РОЗДІЛ 05

Скорочене присвоєння

Запис total = total + 50 трапляється так часто, що для нього придумали скорочення total += 50.

Типова помилка

У Python немає операторів ++ і --, які є в C++ та Java. Збільшити змінну на одиницю можна лише так: count += 1.

РОЗДІЛ 06

Вбудовані функції та модуль math

Частину обчислень робити операторами незручно. Для них є функції: значення передають у дужках і отримують результат.

# Вбудовані функції та модуль math

print(abs(-17))
print(round(3.456, 1))
print(min(55, 40, 70), max(55, 40, 70))
print(math.sqrt(144))
print(math.pi)
print(math.ceil(3.2), math.floor(3.9))
print(round(math.sqrt(2), 4))

round() заокруглює «до парного»: round(0.5) дасть 0, а round(2.5) — 2. Це не збій, а стандарт для фінансових розрахунків.

РОЗДІЛ 07

Оператори відношення

Оператори відношення відповідають на питання «так чи ні» і дають значення типу bool. Саме з них будуються всі умови — тема наступного заняття.

05_compare.py
# Оператори відношення завжди дають True або False
price = 55.0
budget = 100

print(price > budget)
print(price < budget)
print(price == 55)      # == порівняння, = присвоєння
print(price != 55)
print(price >= 55.0)
print(budget <= 100)
print(10 < budget < 200)  # ланцюжок порівнянь — так можна!
print("Латте" == "латте") # регістр має значення
False True True False True True True False # 10 < budget < 200 — ланцюжок порівнянь, як у математиці # "Латте" == "латте" → False: регістр має значення
ОператорЗначенняПрикладРезультат

>= <=більше/менше або дорівнює55 >= 55True
==дорівнює (два знаки!)55 == 55True
!=не дорівнює55 != 55False

А тепер пастка, яка чекає саме на дробові числа. Як гадаєте, що виведе цей код?

# Пастка: дробові числа не можна порівнювати через ==

print(x)
print(x == 0.3)                  # несподівано False!

Запам'ятати

Дробові числа порівнюють або після заокруглення (round(x, 2) == 0.3), або через різницю: «відрізняються менш ніж на мільйонну частку — вважаємо рівними».

РОЗДІЛ 08

Логічні операції and, or, not

Одного порівняння часто замало: «знижка діє, якщо замовлення більше трьох чашок і клієнт має картку».

and

Істина, лише коли обидві умови істинні.

Аналогіящоб вступити, потрібен атестат і заява

or

Істина, коли істинна хоча б одна умова.

Аналогіяплатити можна карткою або готівкою

not

Змінює значення на протилежне.

Аналогія«не зачинено» означає відчинено

06_logic.py
# and, or, not: три логічні операції
is_open = True
has_money = False

print("and:", is_open and has_money)   # обидві умови
print("or: ", is_open or has_money)    # хоча б одна
print("not:", not is_open)             # заперечення

age = 17
group = "ІСТ-11"
print(age >= 16 and group == "ІСТ-11")
print(age < 16 or group == "ІСТ-11")
print(not (age < 16))
and: False or: True not: False True True True

Python обчислює умову зліва направо і зупиняється, щойно результат стає очевидним. У рядках із 10 / x при x = 0 ділення так і не сталося — чому?

07_shortcut.py
# Ліниве обчислення: друга частина рахується не завжди
x = 0

# Python бачить False зліва і навіть не дивиться праворуч
print(x != 0 and 10 / x > 1)

# Перевірка "спершу безпека, потім дія"
cups = 3
total = 165
print(cups > 0 and total / cups > 50)

# or зупиняється на першому True
print(cups == 3 or 10 / x > 1)
False True True # якщо ліворуч від and уже False — правий операнд не обчислюється зовсім # саме так захищаються від ділення на нуль
Типова помилка

Умову «число від 1 до 20» не можна писати як n == 1 or 2 or 3. Правильно: 1 <= n <= 20. Python зрозуміє n == 1 or 2 як (n == 1) or 2, а число 2 саме по собі істинне — умова завжди даватиме True.

РОЗДІЛ 09

Бітові операції (оглядово)

Кожне ціле число зберігається у двійковому вигляді: 12 — це 1100. Бітові операції працюють з окремими двійковими розрядами.

08_bits.py
# Бітові операції працюють з двійковим записом числа
a = 12          # 1100
b = 10          # 1010

print("bin(a) =", bin(a))
print("bin(b) =", bin(b))
print("a & b  =", a & b,  bin(a & b))    # І
print("a | b  =", a | b,  bin(a | b))    # АБО
print("a ^ b  =", a ^ b,  bin(a ^ b))    # виключне АБО
print("a << 1 =", a << 1, bin(a << 1))   # зсув уліво: x2
print("a >> 2 =", a >> 2, bin(a >> 2))   # зсув управо: /4
bin(a) = 0b1100 bin(b) = 0b1010 a & b = 8 0b1000 a | b = 14 0b1110 a ^ b = 6 0b110 a << 1 = 24 0b11000 a >> 2 = 3 0b11 # префікс 0b означає «це двійкове число»
ОператорНазваПравило для кожного біта
&побітове І1 лише там, де в обох числах 1
вертикальна рискапобітове АБО1 там, де хоча б в одному 1
^виключне АБО1 там, де біти різні
<< >>зсувимноження / ділення націло на 2ⁿ
Завдання СРС

Не плутайте & з and: перший працює з бітами чисел, другий — з логічними значеннями. Бітові операції потрібні там, де важливий кожен біт: мережеві маски, права доступу, графіка, шифрування, мікроконтролери.

РОЗДІЛ 10

Введення даних: input()

Щоб програма стала справді корисною, вона має отримувати дані від користувача. Функція input() показує підказку, чекає на Enter і повертає набране як рядок.

# input() ЗАВЖДИ повертає рядок

age_text = input("Ваш вік: ")

print("Тип age_text:", type(age_text))
age = int(age_text)          # рядок -> число
print("Тип age:", type(age))

print("Вітаю,", name)
print("Через 5 років вам буде", age + 5)
Ваше ім'я: Іван Ваш вік: 17 Тип age_text: <class 'str'> Тип age: <class 'int'> Вітаю, Іван Через 5 років вам буде 22 # жирним показано те, що набрав користувач

А тепер та сама програма без перетворення типу. Користувач вводить 12 і 30 — що буде в результаті?

10_input_trap.py
# Пастка: забули int() — замість суми вийшло склеювання
a = input("Перше число: ")
b = input("Друге число: ")
print("a + b =", a + b)           # рядки склеїлися!

Запам'ятати

Два записи рівноцінні: cups = int(input("Скільки? ")) і два окремі рядки — спершу input(), потім int(). Підказка в дужках — не косметика: програма, яка мовчки чекає введення, виглядає зламаною.

f-рядки

Склеювати текст і числа через + незручно: скрізь треба писати str(). Сучасний спосіб — f-рядок. Торкніться частин запису, щоб побачити, що кожна означає.

f"До сплати: {total:.2f} грн"
Торкніться будь-якого елемента коду вище, щоб побачити пояснення.
12_fstring.py
# f-рядок: підставляє значення прямо в текст
drink = "Латте"

total = price * cups

print(f"Замовлення: {drink} x {cups} = {total} грн")
print(f"Ціна однієї чашки: {price} грн")
print(f"Разом з 10% чайових: {total * 1.1} грн")
print(f"Обчислення прямо в дужках: {cups * 2}")
print(f"Знижка 10%: {total * 0.1:.2f} грн")

РОЗДІЛ 12

Помилки та виключення

Синтаксичні помилки не дають програмі навіть початися. Виключення — інша річ: код правильний, але під час виконання сталася ситуація, з якою Python не може впоратися.

cups = 0
average = total / cups
print("Ця строка вже не виконається:", average)

Знизу вгору: останній рядок — тип помилки та опис, вище — номер рядка й сам код. У Python 3.11+ під проблемним місцем малюється «хвиля» ~~~^^^, яка вказує на конкретний фрагмент виразу.

РОЗДІЛ 13

Конструкція try-except

try-except перехоплює виключення: програма пробує виконати ризикований код, а якщо станеться помилка — виконує запасний варіант замість аварійної зупинки.

Порівняйте дві версії однієї програми — без захисту і з ним. Обидві отримують однакові дані: спершу «сто», потім 0 чашок.

try:

Так робити не можна

Порожній except: без типу помилки перехоплює геть усе, зокрема ваші власні одруки в коді. Програма не впаде, але й не працюватиме — а ви не дізнаєтеся чому. Перехоплюйте лише ті помилки, які очікуєте й знаєте, як обробити.

Підсумкова програма теми

Зберемо все разом: введення, арифметика, логіка, форматований вивід і захист від помилок.

18_cafe_final.py
"""Кав'ярня «Байт»: підсумкова програма теми 2.
Читає замовлення, рахує суму зі знижкою та здачу.
"""

PRICE = 55.0          # ціна однієї чашки, грн
DISCOUNT_FROM = 3     # знижка діє від такої кількості чашок
DISCOUNT = 0.10       # 10 %

print("=== Кав'ярня «Байт» ===")

try:
    cups = int(input("Скільки чашок? "))
    paid = float(input("Скільки дали грошей? "))

    total = cups * PRICE
    is_big = cups >= DISCOUNT_FROM
    # is_big — це True/False, а True в арифметиці дорівнює 1
    saved = total * DISCOUNT * is_big
    final = total - saved
    change = paid - final
    enough = change >= 0

    print(f"Замовлення: {cups} x {PRICE:.2f} = {total:.2f}")
    print(f"Знижка: {is_big}, зекономлено {saved:.2f} грн")
    print(f"До сплати:  {final:.2f} грн")
    print(f"Здача:      {change:.2f} грн")
    print(f"Грошей вистачає: {enough}")
except ValueError:
    print("Помилка: кількість і сума мають бути числами")
=== Кав'ярня «Байт» === Скільки чашок? 4 Скільки дали грошей? 250 Замовлення: 4 x 55.00 = 220.00 Знижка: True, зекономлено 22.00 грн До сплати: 198.00 грн Здача: 52.00 грн Грошей вистачає: True
Найцікавіший рядок

saved = total * DISCOUNT * is_big: змінна is_big має тип bool, а True в арифметиці дорівнює 1, False — 0. Множення на is_big або залишає знижку, або обнуляє її. У наступній темі ви навчитеся записувати таке звичніше — через if.
