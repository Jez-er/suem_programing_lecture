РОЗДІЛ 01

Програма, мова програмування, інтерпретатор

Уявіть, що ви пояснюєте другові рецепт кави: «налий 200 мл молока, додай подвійний еспресо, збий піну». Друг виконує кроки один за одним — і отримує латте. Програма — це такий самий рецепт, тільки для комп'ютера: точна послідовність команд, яка приводить до результату.

Проблема в тому, що процесор розуміє лише числа — машинний код. Тому придумали мови програмування: штучні мови, зрозумілі і людині, і (після перекладу) машині. Перекласти програму можна двома способами.

КритерійКомпіляція (C, C++, Go)Інтерпретація (Python, JS)
Коли перекладається кододин раз, до запускущоразу під час запуску
Що потрібно користувачутільки готовий файлвихідний код + інтерпретатор
Швидкість виконаннявищанижча
Швидкість розробкинижча: після кожної зміни — перекомпіляціявища: змінив — одразу запустив
Де шукати помилкукомпілятор покаже всі одразуінтерпретатор зупиниться на першій
Запам'ятати

Файл .py — це звичайний текст. Його «оживляє» інтерпретатор python, який треба встановити на комп'ютер. Python — інтерпретована мова.

РОЗДІЛ 02

Знайомство з Python: історія та сфери

Python створив нідерландець Гвідо ван Россум; перша версія вийшла у 1991 році. Назва — не від змії, а від комедійного шоу «Monty Python's Flying Circus». Головна ідея мови: код читають набагато частіше, ніж пишуть, тому він має бути максимально простим.

РікПодія

2008Python 3.0 — сучасна гілка, несумісна з Python 2
2020підтримку Python 2 припинено
2023–2025Python 3.12–3.13: швидший інтерпретатор, кращі повідомлення про помилки

Оберіть сферу — побачите, які бібліотеки там використовують і що для цього треба вміти.

Не для новачків

Python — професійний інструмент Instagram, YouTube, Spotify, Netflix і NASA, який просто також добре підходить для навчання. Де його майже не використовують: мобільні застосунки, ігри з важкою графікою, системи, де важлива кожна мілісекунда.

РОЗДІЛ 05

Перша програма. Два режими роботи

Створіть файл 01_hello.py і натисніть ▶. Але спершу — подумайте, що саме з'явиться в терміналі.

01_hello.py
# Перша програма: одна команда — один рядок на екрані
print("Привіт, коледж!")
Привіт, коледж! # коментар після # інтерпретатор не читає

Торкніться будь-якої частини рядка, щоб дізнатися, що вона означає.

print("Привіт, коледж!")
# одна команда — один рядок на екрані
Торкніться будь-якого елемента коду вище, щоб побачити пояснення.

Файл чи інтерактивний режим?

Якщо в терміналі набрати просто python, відкриється інтерактивна оболонка — запрошення >>>. Команда — одразу результат. Цей режим називають REPL: Read — Eval — Print — Loop.

calc.py
2 + 3
print("Привіт")
55.0 * 3
Привіт # 2 + 3 і 55.0 * 3 обчислено й забуто: у файлі результат видно лише через print()
Термінал
>>> 2 + 3
>>> print("Привіт")
>>> 55.0 * 3
>>> exit()
5 Привіт 165.0 # інтерактивний режим сам показує результат кожного виразу
Файл .pyРежим >>>
Як запустити▶ у VS Code або python hello.pypython у терміналі
Код зберігаєтьсятакні, зникає після закриття
Результат виразулише через print()показується сам
Для чогопрограми, які запускають багато разівшвидкі експерименти
РОЗДІЛ 06

Алфавіт мови та структура програми

Алфавіт мови — набір символів, з яких складається програма: латинські літери (великі й малі — різні!), цифри, спеціальні символи + - * / = ( ) : , . ' " # _ та пробіли, які в Python мають значення.

Рядок коду інтерпретатор розбиває на «слова» — лексеми:

ЛексемаПрикладЩо це
Ідентифікаторtotal, priceім'я змінної, функції, модуля
Ключове словоif, True, importслово, зарезервоване мовою
Літерал55.0, "Латте"значення прямо в коді
Оператор=, *, ==дія над значеннями
Коментар# сумапояснення для людини

Правила для імен: починаються з літери або _, далі літери, цифри, _; не збігаються з ключовими словами. Перевірте себе — яке з імен правильне?

Програма — послідовність інструкцій, по одній у рядку; виконання йде з першого рядка до останнього, окремої точки входу не треба. А що буде, якщо поставити зайвий відступ?

12_indent_error.py
# Навмисна помилка: зайвий відступ
print("Початок")
    print("Цей рядок з відступом")
File "12_indent_error.py", line 3 print("Цей рядок з відступом") IndentationError: unexpected indent
Запам'ятати

Відступ — 4 пробіли. VS Code ставить їх сам при натисканні Tab. Змішувати пробіли й табуляції не можна.

РОЗДІЛ 07

Стиль коду PEP 8 і коментарі

PEP 8 — офіційна угода про те, як має виглядати код на Python. Її дотримуються всі професійні команди, і за нею ж перевірятимуться ваші роботи. Порівняйте два варіанти того самого коду.

10_pep8_bad.py
# Так працює, але так НЕ пишуть (порушення PEP 8)
Name="Латте";Price=55.0
cups=3
print( Name,Price*cups )
Латте 165.0 # працює! але спробуйте знайти тут помилку через тиждень
11_pep8_good.py
# Той самий код за PEP 8: пробіли, один вираз у рядку
name = "Латте"
price = 55.0
cups = 3
print(name, price * cups)
Латте 165.0 # той самий результат — і читається з першого погляду
ПравилоПравильноНеправильно
Імена — малими через _ (snake_case)total_priceTotalPrice
Пробіли навколо операторівx = a + bx=a+b
Без пробілів усередині дужокprint(x)print( x )
Одна інструкція в рядкудва рядкиa = 1; b = 2
Відступ 4 пробіли, рядок до 79 символівтабуляція, довгі рядки
Зрозумілі імена англійськоюcups_countc, kilkist
Коментарі

Починаються з #. Хороший коментар пояснює чому, а не що: cups = 3 # три чашки — марний, cups = 3 # мінімум для доставки — корисний. Довгий опис на початку файлу — у потрійних лапках """...""".

РОЗДІЛ 08

Змінні та літерали

Щоб порахувати вартість замовлення, треба десь «тримати в голові» ціну, кількість і назву напою. У програмі для цього є змінні — імена, прив'язані до значень. Літерал — значення, записане прямо в коді: 55.0, 3, "Латте", True.

Змінна створюється присвоєнням =: ліворуч ім'я, праворуч значення. Оголошувати її окремо, як у C++ чи Java, не треба.

02_cafe.py
# Кав'ярня «Байт»: зберігаємо дані у змінних
name = "Латте"          # рядок (str)
price = 55.0            # дробове число (float)
cups = 3                # ціле число (int)
is_open = True          # логічне значення (bool)

print("Напій:", name)
print("Ціна:", price)
print("Чашок:", cups)
print("Відчинено:", is_open)
print("До сплати:", price * cups)
Напій: Латте Ціна: 55.0 Чашок: 3 Відчинено: True До сплати: 165.0 # print приймає кілька аргументів через кому і виводить їх через пробіл

Ярлик можна переклеїти на іншу «коробку» — навіть іншого типу. Що виведе програма?

04_dynamic.py
# Динамічна типізація: одна змінна — різні типи в різний час
x = 7
print(x, type(x))
x = "сім"
print(x, type(x))
x = 7.0
print(x, type(x))
7 <class 'int'> сім <class 'str'> 7.0 <class 'float'> # у C++ або Java такий код не скомпілювався б

А тепер змінна, якій ще нічого не присвоєно:

13_name_error.py
# Навмисна помилка: змінна ще не існує
print(total)
total = 10
Traceback (most recent call last): File "13_name_error.py", line 2, in <module> print(total) ^^^^^ NameError: name 'total' is not defined
Типова помилка

NameError найчастіше означає одрук в імені (pricе з кириличним «е», Price замість price) або використання змінної до присвоєння.

РОЗДІЛ 09

Базові типи даних

Кожне значення має тип — він визначає, що зі значенням можна робити: числа додають, рядки склеюють, логічні значення перевіряють в умовах.

int

Цілі числа: 42, -7, 1_000_000. Без обмеження за розміром.

У кав'ярнікількість чашок

float

Дробові: 3.14, 55.0, 1e3. Роздільник — крапка. Точність ~16 цифр.

У кав'ярніціна, вага зерна

str

Текст у лапках: "Латте", 'a'. + склеює, * повторює, len() рахує символи.

У кав'ярніназва напою

bool

Лише True і False. Результат порівнянь: ==, !=, >, <.

У кав'ярнічи відчинено

06_numbers.py
# Цілі числа необмежені, дробові — з похибкою
big = 2 ** 100
print(big)
print(0.1 + 0.2)
print(round(0.1 + 0.2, 2))
print(10 / 4)       # ділення завжди дає float
print(10 // 4)      # ціла частина від ділення
print(10 % 4)       # остача
print(1_000_000)    # підкреслення для читабельності

Латте велика -------------------- 5 Він сказав: "Смачно!" It's ok Кав'ярня «Байт» працює з 8:00 # \ перед лапкою: «це не кінець рядка, а звичайний символ»

# Логічний тип: True / False і порівняння

Типова помилка

"55" у лапках — це рядок, а не число. "55" + 1 викличе TypeError; спершу треба перетворити рядок у число — наступний розділ.

РОЗДІЛ 10

Перевірка та перетворення типів

Функція type() повертає тип будь-якого значення. Зверніть увагу на останній рядок: що дає float * int?

03_types.py
# Функція type() показує, до якого типу належить значення
name = "Латте"
price = 55.0
cups = 3
is_open = True

print(type(name))
print(type(price))
print(type(cups))
print(type(is_open))
print(type(price * cups))
<class 'str'> <class 'float'> <class 'int'> <class 'bool'> <class 'float'> # float * int → float: Python обирає «ширший» тип, щоб не втратити дробову частину

Для перевірки в умовах зручніша isinstance() — вона відповідає True або False:

09_isinstance.py
# isinstance() відповідає True/False: "чи це значення такого типу?"
price = 55.0
cups = 3
print(isinstance(price, float))
print(isinstance(cups, int))
print(isinstance(cups, str))
print(isinstance(True, int))     # bool — підвид int
print(isinstance("55", (int, float)))
True True False True False

Явне перетворення

Функції int(), float(), str(), bool() створюють значення потрібного типу. Оберіть перетворення й подивіться, що вийде:

05_convert.py
# Перетворення типів: str -> int -> float -> str
text = "12"             # це рядок, а не число!
print(text + text)      # склеювання рядків
number = int(text)      # тепер це ціле число
print(number + number)  # додавання чисел
print(float(number))    # ціле -> дробове
print(str(number) + " грн")  # число -> рядок
print(int(3.99))        # дробова частина відкидається
print(bool(0), bool(5), bool(""), bool("0"))
1212 24 12.0 12 грн 3 False True False True # "12" + "12" — склеювання; int(3.99) відкидає дробову частину; рядок "0" — істинний
Запам'ятати

type() — подивитися тип, isinstance() — перевірити в умові, int()/float()/str()/bool() — перетворити. input() завжди повертає рядок — це головний випадок перетворення (тема 2).
