# Основи програмування мовою Python (ОК 11)

> Інтерактивний адаптивний веб-курс з основ програмування мовою Python з можливістю запусків прикладів коду, перевіркою анатомії синтаксису, вікторинами, чек-листами та практичними завданнями у форматі DOCX.

---

## 🌟 Про проєкт

**`suem_programing_lecture`** — це сучасний веб-додаток (Single-Page Application), розроблений для вивчення курсу «Основи програмування мовою Python» (Змістовий модуль 1).

Проєкт поєднує теоретичний матеріал, наочні діаграми, інтерактивні блоки коду з можливістю запуску, візуальну анатомію синтаксису, підсумкові вікторини з миттєвою перевіркою, словник термінів та завантажувані практичні завдання для студентів.

---

## ✨ Основні можливості

- **⚡ Інтерактивний запуск коду**: Перегляд консольного виводу прикладів Python безпосередньо на сторінці лекції.
- **🔍 Анатомія синтаксису**: Клікабельні токени коду (`print()`, дужки, лапки, коментарі), що пояснюють призначення кожного елемента.
- **🚀 Швидкий SPA-роутер**: Клієнтська навігація без перезавантаження сторінки з підтримкою підсвічування активних розділів, плавного скролінгу до якорів (`#s1`, `#quiz`) та коректного ігнорування статичних файлів.
- **📥 Завантаження практичних робіт (.docx)**: Прямі кнопки завантаження практичних завдань у форматі Microsoft Word для кожної лекції.
- **🎯 Інтерактивні вікторини**: Тестування в кінці лекцій з автоматичним підрахунком балів та вичерпним фідбеком до відповідей.
- **🔍 Словник термінів з live-пошуком**: Пошуковий фільтр по глосарію основних понять програмування.
- **📋 Збереження прогресу**: Чек-листи засвоєння практичних навичок зі збереженням стану в `localStorage`.
- **📱 Responsive & Dark Mode Design System**: Повнофункціональна мобільно-перша верстка, адаптована для екранів від 360px до десктопів 1200px+ із підтримкою темної теми.

## 🛠️ Технологічний стек

- **Мова розробки**: TypeScript 5+, HTML5, CSS3 (Modern Custom Properties, Flexbox, CSS Grid)
- **Збирач та Dev-сервер**: Vite 8+
- **Пакетний менеджер**: pnpm / npm
- **Шрифти**: Google Fonts (`Unbounded`, `Commissioner`, `JetBrains Mono`)
- **Маршрутизація**: Кастомний SPA-роутер на Vanilla TypeScript (HTML5 History API)

## ⚡ Швидкий запуск та розробка

### 1. Установка залежностей:
```bash
pnpm install
```

### 2. Запуск сервера розробки:
```bash
pnpm dev
```
Після запуску відкрийте у браузері: `http://localhost:5173/`

### 3. Збірка для продакшену:
```bash
pnpm run build
```
Готові оптимізовані файли збірки будуть створені у директорії `dist/`.

### 4. Попередній перегляд збірки:
```bash
pnpm preview
```
